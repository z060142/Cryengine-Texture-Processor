# texproc GUI — 五個 UX 設計標的（純美術 → 純工程師）

共同基礎功能（五案皆備，只是呈現哲學不同）：
匯入貼圖（檔案/資料夾/拖放）→ 自動分組 → unknown 人工指派 → 設定 → 批次轉換 + 進度 → 輸出摘要；FBX 材質轉換為獨立副目標；設定存讀。

共用假資料：KB3D 132 groups / 5 unknown（refraction）、AtlasA（7 圖）、GlassClean（6 圖+1 unknown）、car.fbx（16 材質 + `<unassigned>`）。

---

## 案 1「暗房」— 純美術

**使用者**：完全不想知道什麼叫 glossiness 的美術。心智模型 = 沖印店：把底片丟進去，取件。
**手感**：全螢幕拖放區起手；素材進來變成**一疊疊拍立得卡片**（每組一疊，封面是 basecolor 縮圖）；有問題的疊（unknown）角落亮橘點，點開卡片翻面用**圖示**（不是字）選型別。設定不存在——只有右上三個**預設檔**（遊戲資產 / 高精度 / 快速預覽）。底部一顆大圓鈕「沖洗」，進度 = 卡片逐疊顯影動畫。FBX 拖進來就變成一張「材質底片」卡，同一顆鈕一起沖。
**藏什麼**：所有術語、所有核取框、目錄選擇（固定輸出到來源旁的 `_cryengine/`，完成後開資料夾）。

## 案 2「燈箱」— 美術偏向

**使用者**：看圖工作的美術/材質師，願意調參數但要**所見即所得**。
**手感**：左側 filmstrip（分組縮圖直排，狀態色框：綠好/橘待處理）；中央大預覽，上方通道切換 pill（Diffuse / Normal / Spec / Height / 最終合成），**滑桿即時反映在預覽**（AO 強度、亮度）；右側是「這一組」的檢視器：型別格子用縮圖呈現、unknown 直接拖到正確格子。批次 = 頂部「全部轉換」，進度嵌在 filmstrip 每格上。FBX 是左下第二個空間（Material 模式），切換後同構：材質清單 filmstrip + 中央槽位視覺化。
**藏什麼**：批次表格、診斷文字（轉成色框與 tooltip）。

## 案 3「工作台」— 中線（原版現代化）

**使用者**：技術美術/TD，原版使用者。心智模型 = 原 PySide 三欄，但修掉原版的雜訊。
**手感**：左欄兩個 tab（貼圖匯入 / 模型匯入）+ 檔案清單；中欄上預覽下分組表（分組表 = 型別欄位格線，unknown 內嵌下拉）；右欄設定面板（常用五項 + Advanced 摺疊）+ 「批次處理」「僅輸出貼圖」「輸出材質」三鈕。進度 = 模態進度列 + 可取消（原版 progress_dialog 的位置）。一切都在原版使用者肌肉記憶的位置上。
**藏什麼**：不藏，但分層（Advanced 摺疊、診斷收進狀態列點開）。

## 案 4「檢核站」— 工程偏向

**使用者**：管線工程師，在乎**先看清楚會發生什麼再按鈕**。心智模型 = code review / CI。
**手感**：主體是**可排序資料表**（檔案 → 判定型別 → 規則來源 → base name → 目標輸出），內嵌編輯；上方三段式流程列「1 掃描 → 2 檢核 → 3 執行」。第 2 步是**Dry-run 計畫視圖**：每組展開顯示將執行的 INT/OUT 規則鏈與輸出檔名，DEF 診斷以黃/紅列內嵌。設定是左側表單 + 右側等價 settings JSON 即時預覽（雙向）。執行後表格變成結果視圖（時間、尺寸、hash）。FBX 是同一張表的另一個資料來源 tab，材質槽表 + request 預覽。
**藏什麼**：縮圖預覽縮到 hover tooltip；美化元素零。

## 案 5「終端機」— 純工程師

**使用者**：住在 CLI 的人，要 GUI 只因為要看批次狀態與 diff。心智模型 = k9s / lazygit。
**手感**：單螢幕深色等寬字介面：左窄欄 job 佇列（scan/process/convert 各為 job），中央依選取 job 顯示**管線 DAG**（INT→OUT 節點，點節點看該步輸入輸出），右欄 raw JSON（groups/settings，可直接編輯、schema 即時驗證）；底部常駐 log stream。**每個 GUI 動作即時顯示等價 CLI 指令**（一鍵複製）——GUI 是 CLI 的透明外殼。全鍵盤可操作（j/k 移動、: 命令面板）。FBX = converter job，同一佇列。
**藏什麼**：縮圖與視覺預覽全部沒有；只有資料。

## Demo 規格（五案共通）

- 單一自包含 HTML（無外部資源），zh-TW 文案，桌面 1280+ 佈局。
- 假資料照上方共用集；縮圖用 CSS 漸層/內嵌 SVG 模擬。
- 必須可互動走完：匯入（按鈕模擬）→ 分組出現 → 指派一個 unknown → 改一個設定 → 按轉換 → 假進度 → 完成摘要；FBX 副流程至少可切換檢視。
- 目的為評估**手感與資訊架構**，非視覺完稿。
