# UI 研究第二輪（R2）：五個「設計理念驅動」的中間帶方案

> 2026-07-29。背景：v2.1.0 後選項大量增加（metal gate、批次 FBX、多 RC、
> 多語、清理選項…），且即將加入：材質預覽、模型預覽、proxy 生成參數、
> diffuse→完整 PBR 貼圖轉換器。業主裁示：
> 1. **不做**純美術與純工程師兩極（皆不好用），五案全取中間帶；
> 2. 以**設計理念**區分方案，而非美術⇄工程師光譜位置；
> 3. 模型與貼圖介面**分得更開**（獨立子頁面），新功能各有其位，
>    互不污染參數面板——「只處理需要的部分」，反飛機儀表板。

## 共用功能清單（每案都必須安置，不得遺漏）

**貼圖側**：導入（檔案/資料夾/拖放）、群組審閱表（型別欄）、群組級設定、
轉換設定（解析度、diffuse 格式、normal 翻轉、metal gate 進階）、
RC/DDS（路徑、自適應池進度、導出後清理選項）、關聯貼圖、多選刪除、
**新：材質預覽**、**新：diffuse→PBR 轉換器（參數 + 執行）**。

**模型側**：FBX 清單（批次）、材質槽（physicalize 多選）、軸向（偵測+覆寫）、
單位/縮放、合併節點、場景原點、導出選項（隨模型導出貼圖、刪 json）、
**新：模型預覽**、**新：proxy 生成參數（演算法參數 + 生成/預覽/接受）**。

**全域**：語言、輸出目錄、工作/進度中心、診斷、設定檔存取。

## 五案理念

### R2-1「流程」（Flow）— `r2-demo1-flow.html`
理念：**工作即流程**。UI 按管線階段組織：Import → Review → Convert →
Export 四階段各一頁，頂部 stepper 顯示進度與各階段完成狀態；貼圖流與
模型流是兩條平行泳道（可各自走到不同階段）。每頁只有該階段的控件；
proxy 生成是模型流 Review 階段的一站、PBR 轉換器是貼圖流 Import 後的
可選一站。適合：把「做完一批」視為一趟旅程的使用者。

### R2-2「空間」（Spaces）— `r2-demo2-spaces.html`
理念：**空間即任務**（Blender 式）。頂層分頁：Textures / Models / Lab
（proxy 生成、PBR 轉換器等工具間）/ Queue。每個空間是完整獨立子頁面，
擁有自己的預覽區與參數欄；共用的只有頂欄（語言/輸出目錄/全域進度膠囊）。
切空間 = 切心智模式，空間內再無其他空間的任何控件。適合：一次只做
一種事、但常在多種事之間切換的使用者。

### R2-3「選中」（Selection）— `r2-demo3-selection.html`
理念：**選中即上下文**。恆定三欄：左＝資產導航器（貼圖群組樹 + 模型樹，
兩個可折疊分區）；中＝預覽（選貼圖群組→材質球/平鋪預覽，選模型→3D
預覽，選 proxy 節點→線框疊加）；右＝檢視器（inspector）**只顯示當前
選中物的參數**。沒選中就近乎空白；全域設定收進齒輪抽屜。proxy 參數
與 PBR 轉換器都是「選中對應資產時 inspector 出現的分頁」。適合：
以資產為單位思考、討厭常駐面板的使用者。

### R2-4「模組」（Modules）— `r2-demo4-modules.html`
理念：**模組即卡片**。首頁是儀表：四張大卡片（Texture Convert /
Model Export / Proxy Generator / PBR Builder）各顯示摘要狀態（待處理數、
上次結果、進行中進度）；點卡片進入該模組的全螢幕專注頁，只有該模組
的控件與預覽，左上返回。工作佇列與通知在底部常駐細條。適合：
任務導向、喜歡「進去做完就出來」的使用者。

### R2-5「預覽」（Stage）— `r2-demo5-stage.html`
理念：**預覽即中心**（DCC 式舞台）。中央大 viewport（2D 材質平鋪 / 3D
模型 / proxy 線框三模式切換），左側細軌切換工作模式（Textures / Models /
Proxy / PBR），所有參數都在右側**可折疊面板堆**中、且按模式自動換組；
面板預設折疊只留標題，展開哪個用哪個——使用者自己組出最小儀表板。
底部時間軸式進度條。適合：邊看邊調、以視覺回饋為主的使用者。

## Demo 製作約束（五個 agent 共用）

- 純靜態 HTML+CSS+最小 JS（分頁/折疊切換用），單檔自足、無外部資源。
- UI 文字用英文；假資料要像真的（KB3D 檔名、真實選項名）。
- 每案必須逐項安置「共用功能清單」全部項目——寧可收進抽屜也不得省略；
  demo 內用一個隱藏註解區塊列 checklist 自證。
- 視覺基調延續現行 egui 深色工作台（參考 demo3-workbench.html），
  但版面理念按各案發揮。
- 桌面 1280×800 為準；不需要 RWD。
- 檔名固定（見各案標題），只寫自己的檔案。
